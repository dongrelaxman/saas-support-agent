# Projects and Tasks Basics

## Views
Each project supports List, Board (Kanban), and Calendar views. Timeline view is available on Pro and above.

## Recurring tasks
Open a task, choose Repeat, and select daily, weekly, monthly, or custom. A new copy is created when the previous one is completed.

## Archiving
Archive a project from Project settings > Archive. Archived projects do not count toward the Free plan project limit and can be restored at any time.

## Keyboard shortcuts
Press ? anywhere in the app to see all shortcuts. Press C to create a task and / to search.
