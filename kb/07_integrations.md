# Integrations

## Supported integrations
TaskPilot integrates with Slack, GitHub, and Google Drive. Connect them under Settings > Integrations.

- Slack: post task updates to channels and create tasks with the /taskpilot command.
- GitHub: link pull requests and commits to tasks by including the task ID in the message.
- Google Drive: attach Drive files to tasks without uploading copies.

## Importing from Jira
Go to Settings > Import > Jira. We import projects, tasks, and comments. Attachments and custom workflows are not imported.

## API
The REST API is available on all plans. Rate limits are 100 requests per minute on Free, 600 per minute on Pro, and 1,200 per minute on Business. Enterprise limits are negotiated.
API tokens are created under Settings > Developer. Tokens can be revoked at any time.
